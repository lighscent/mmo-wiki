# Enchères (`/ah`)

- Vendez et achetez des items via le GUI
- **Vendre** : `/ah sell <prix>` en main → l'item est mis en vente
  - Suffixes : `k` (mille), `m` (million), `b` (milliard)
- **Chercher** : `/ah <mot-clé>` → filtre par nom d'item
- **GUI** : `/ah` → navigation avec tri cyclable
- **Retour** : `/ah return` → récupère les items invendus expirés
- **Expiration** : 7 jours
