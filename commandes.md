# Commandes

| Commande | Description | Alias |
|---|---|---|
| `/help` | Affiche le menu d'aide | |
| `/spawn` | Téléportation au spawn | |
| `/sethome <nom>` | Définit un home à votre position | |
| `/delhome <nom>` | Supprime un home | |
| `/home <nom>` | Téléportation à un home | |
| `/balance` | Voir votre solde | `/bal`, `/money` |
| `/pay <joueur> <montant>` | Payer un joueur | |
| `/rtp` | Téléportation aléatoire dans le monde | `/wild`, `/randomtp` |
| `/tpa <joueur>` | Demande de téléportation à un joueur | |
| `/tpahere <joueur>` | Demander à un joueur de se téléporter à vous | |
| `/tpaccept` | Accepter une demande de téléportation | |
| `/tpdeny` | Refuser une demande de téléportation | |
| `/ah` | Enchères — ouvre le GUI | `/auction`, `/auctions` |
| `/ah sell <prix>` | Met en vente l'item en main | |
| `/ah <recherche>` | Cherche un item par nom | |
| `/ah return` | Récupère les items invendus expirés | |
| `/back` | Téléportation à l'emplacement de votre mort (liste pour VIP/ULTIME) | |
| `/death-list <joueur>` | (Staff) Liste toutes les morts d'un joueur avec coordonnées cliquables | |
| `/axommo reload` | (OP) Recharge la config | |
| `/mobcap` | (Staff) Affiche l'utilisation du mob cap par joueur | |
